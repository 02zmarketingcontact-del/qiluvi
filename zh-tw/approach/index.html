How We Work

01 — 確認需求

了解決策、負責人、錯誤成本及期限。

Output: 需求簡報與驗收條件

02 — 資料查證

登錄來源，區分VERIFIED/SUPPORTED/HYPOTHESIS/UNKNOWN。

Output: 來源與風險紀錄

03 — 方案比較

依明確假設比較各種路徑與風險。

Output: 決策比較矩陣

04 — 書面提案

確認工作範圍、費用、專業夥伴與變更管理。

Output: 提案與服務範圍

05 — 工作執行

追蹤任務、來源、成本及專業審查依賴。

Output: 行動紀錄與交付文件

06 — 品質與交付

檢查資訊、範圍、時程與未決問題。

Output: 品質檢查與驗收文件

02

證據狀態

  • VERIFIED — 在特定範圍具有可靠的直接證據。
  • SUPPORTED — 有資訊來源支持，但適用範圍有限。
  • HYPOTHESIS — 仍需買方或其他來源驗證。
  • UNKNOWN — 目前不足以作出結論。
