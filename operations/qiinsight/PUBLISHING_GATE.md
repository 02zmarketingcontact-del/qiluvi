# QiInsight publication gate

1. Rights: record source URL, publisher, usage terms, rights classification. RIGHTS_REVIEW or PROHIBITED blocks publishing.
2. Factual: preserve claim-to-source mapping; independently verify consequential claims; record conflicts.
3. Editorial: original structure and interpretation, not paragraph-level rewriting or unlicensed translation; local editorial review per locale.
4. Technical: canonical, correct hreflang, indexability, localized metadata and internal links.
5. Publication: only APPROVED event and REVIEWED locale may transition to PUBLISHED after live URL verification.

Automation must create drafts only until the above gates are implemented and checked. Never infer permission from public accessibility or RSS presence.
