# QILUVI — Independent Corporate Website

QILUVI là website doanh nghiệp độc lập, với 5 nhóm dịch vụ và liên kết sang sản phẩm QiMap.

## Website structure
- `index.html`: responsive one-page website, built-in CSS and JavaScript; Vietnamese, English, Simplified Chinese, Traditional Chinese.
- `assets/qiluvi-icon.svg`: scalable QILUVI-inspired branding icon.
- `qimap/index.html`: browser redirect to the existing QiMap map.

## GitHub Pages
1. Open **Settings → Pages** in this `qiluvi` repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main`, folder `/(root)`, then **Save**.
4. Once GitHub confirms deployment, open https://02zmarketingcontact-del.github.io/qiluvi/

The repository and content exist independently from `atlas-bds-tphcm`. QiMap is only linked by URL; its files and data have not been moved or changed.
